# Things to do — React Todo List

A responsive Todo application built with React and Vite. Add tasks, edit pending
task descriptions, mark tasks complete, remove completed tasks, and filter the
list by status.

## Run locally

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```

## Features

- Add a task description without validation or character limits.
- Edit pending tasks inline, with **Cancel** and **Confirm** actions.
- Mark pending tasks as completed. Completed descriptions are crossed out and
  shown in green; completed tasks cannot be edited or marked pending again.
- Delete completed tasks after confirming the action.
- Show completed tasks before pending tasks in the **All tasks** view.
- Filter the list by all, pending, or completed tasks.
- Display task counts, an empty state, and filters only while tasks exist.
- Responsive layout with keyboard-visible focus states and reduced-motion
  support.
